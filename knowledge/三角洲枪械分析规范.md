# 三角洲枪械分析规范

> 状态：第一版结构模板  
> 数据原则：本文件不包含任何未经用户提供或未经来源核验的武器、配件、护甲、生命值或版本数值。

## 1. 用途与边界

本文件用于组织三角洲相关枪械分析中的来源、单位、武器参数、配件修正、目标模型、命中模型和评分方案。

本文只定义分析框架。实际数值必须注明平台、版本、模式、测试方法和来源。

## 2. 来源元数据

| 字段 | 含义 |
|---|---|
| `source_id` | 唯一来源编号 |
| `platform` | 适用平台 |
| `build_or_version` | 游戏构建号或版本 |
| `mode` | 适用模式 |
| `captured_at` | 数据记录时间 |
| `source_type` | 用户实测、界面转写、公告、数据文件等 |
| `locator` | 链接、截图、视频时间点或文件位置 |
| `measurement_method` | 测量步骤与工具 |
| `verification_status` | 待核验、已核验、有冲突 |
| `notes` | 误差、限制和冲突 |

## 3. 分析术语

- **基础参数**：来源直接给出的原始字段，不包含计算推导。
- **派生指标**：由基础参数和计算假设得到的指标。
- **伤害距离段**：使用同一伤害或衰减规则的距离区间；边界必须由来源确认。
- **射击间隔**：相邻射击事件之间的时间，需要说明是否由射速换算。
- **理论击杀时间**：在给定命中、伤害和计时约定下的计算结果。
- **实战命中模型**：用命中概率、命中部位或散布描述的计算假设。
- **后坐力与散布指标**：必须附定义和测量方法，不能只用界面名称代替物理含义。
- **标准化评分**：将不同单位指标转换到共同区间后进行的工具性评分。

## 4. 单位约定

每个数值字段必须带单位或写明无量纲，例如：

- 距离：待填写单位；
- 时间：待填写单位；
- 射速：待填写单位；
- 伤害：游戏内数值单位；
- 角度、散布或后坐力：按来源定义填写；
- 概率：使用 `[0, 1]` 或百分比，并保持同一数据集一致。

禁止在来源没有换算依据时混用单位。

## 6. 计算约定

- 射速换算射击间隔前，确认射速单位和计时模型；
- 击杀发数必须说明生命值等于累计伤害时是否判定击杀；
- 击杀时间必须说明第一发发生在 `t = 0` 还是经过一次射击间隔后；
- 命中率、命中部位和后坐力模型若无来源，应标记为【计算假设】；
- 配件修正必须记录加法、乘法、覆盖或分段规则及应用顺序；
- 评分必须公开指标方向、标准化方式和权重；
- 理论结果不得直接描述为实际对局表现。
