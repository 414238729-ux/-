# 通用概率分析规范

> 状态：第一版结构模板  
> 适用范围：不依赖具体游戏的概率、枚举、模拟和统计报告。

## 1. 目标

本规范用于把自然语言随机机制转换为可复现的数学模型，并统一精确计算、蒙特卡洛模拟、误差报告和输入记录方式。

## 2. 来源元数据

当分析依赖用户规则、数据集、规则书或其他资料时，至少记录：

| 字段 | 含义 |
|---|---|
| `source_id` | 本资料库中的唯一来源编号 |
| `title` | 规则、数据集或资料名称 |
| `source_type` | 用户粘贴、规则书、数据文件、实测记录等 |
| `locator` | 页码、章节、链接、文件位置或消息位置 |
| `version_or_date` | 资料版本、数据日期或记录日期 |
| `verification_status` | 待核验、已核验、有冲突 |
| `notes` | 适用范围、误差、缺失项和冲突说明 |

纯数学定义不需要伪造外部来源；若使用某个具体游戏的概率或总体数据，必须关联对应 `source_id`。

## 3. 术语

- **样本空间**：一次完整试验所有可能结果的集合。
- **事件**：样本空间中满足指定条件的结果集合。
- **随机变量**：把试验结果映射为数值的函数。
- **条件概率**：已知事件发生时另一个事件的概率。
- **独立**：一个事件的发生不改变另一个事件的概率；不得仅因事件相邻就假设独立。
- **放回抽取**：抽取后对象返回总体，后续总体组成不变。
- **不放回抽取**：抽取后对象不返回总体，后续概率随状态改变。
- **期望值**：随机变量按概率加权的平均值。
- **中位数**：累计概率达到至少 0.5 时对应的分位位置。
- **总体标准差**：描述结果自身离散程度的统计量。
- **标准误**：描述统计估计量因有限模拟次数产生的抽样波动。
- **分位数**：累计概率达到给定比例时的结果位置。
- **蒙特卡洛模拟**：用重复随机试验估计目标分布或统计量。
- **随机种子**：初始化伪随机数生成器、用于复现实验的输入。
- **置信区间**：在指定统计模型下描述估计不确定性的区间，不代表规则本身正确的概率。
- **截断**：试验因人工上限停止，而非自然终止。

## 4. 证据与假设层级

每个模型都应分开保存：

1. 规则原文或数据来源；
2. 从原文得到的推断；
3. 为计算补充的假设；
4. 数学模型或算法；
5. 精确结果或模拟结果；
6. 误差、敏感性与限制。

## 6. 方法选择

优先顺序：

1. 确定性计算；
2. 封闭公式；
3. 完整枚举；
4. 动态规划或状态压缩；
5. 蒙特卡洛模拟。

只有在更高优先级方法不合理或代价过高时，才使用下一种方法。模拟逻辑应尽可能用小规模精确案例校验。

## 7. 统计与误差规范

### 精确结果

- 给出概率质量函数或目标统计量；
- 说明状态空间与枚举是否完整；
- 不报告模拟标准误；
- 离散分位数采用逆累计分布定义。

### 模拟结果

默认报告：

- 试验次数和有效样本数；
- 随机种子；
- 均值、中位数、总体标准差；
- P5、P25、P50、P75、P95；
- 各离散结果的次数和经验概率；
- 均值标准误与 95% 区间；
- 事件概率的标准误或 Wilson 95% 区间；
- 达到重复硬上限的次数或比例。

模拟误差不包含：

- 输入数据错误；
- 规则解释错误；
- 模型简化；
- 版本差异；
- 策略选择偏差。

## 8. 输入校验

- 试验次数必须为正整数；
- 抽取数量必须是非负整数且不得超过可抽对象数量；
- 概率必须是有限非负数，概率和必须为 1；
- 权重必须是有限非负数，且至少一个权重大于 0；
- 数值样本不得为空，不得包含 NaN 或无穷大；
- 分位点必须位于 `[0, 1]`；
- 重复触发必须设置正整数硬上限；
- 单位必须明确且保持一致。
