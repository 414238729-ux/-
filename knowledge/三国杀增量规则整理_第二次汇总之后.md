### 2. 手气卡

【当前确认】

普通八人军争暂时启用最多8次手气卡／整手重摸口径。

【分析约定】

1. 每名角色根据自身技能、身份、座位和公开主公决定是否保留当前整手。
2. 不得使用未公开身份。
3. 不得读取对手隐藏手牌。
4. 必须在报告中注明实际采用的手气卡机制及最大次数。
5. 若未来改用其他次数，应建立明确版本号或配置，不得静默覆盖旧结果。

建议配置：

`identity_mulligan_max_rerolls = 8`

手气卡策略必须属于AI策略层，不得写成卡牌效果。

### 6. 被测武将与主公匹配

【分析约定】

- 被测武将固定为主公；
- 其余7名武将从普通候选池无放回抽取；
- 单独统计被测武将主公胜率；
- 不用随机抽到主公的少量样本代替专项主公测试。

#### 忠臣

- 主公优先从与被测武将有一定协同、但不过度绑定的预登记子池抽取；
- 同时保留完整主公池结果；
- 不得只选择最有利主公。

#### 反贼

- 主公从不直接封锁该武将核心机制的主公中抽取；
- 明显克制主公作为独立专项测试；
- 不得通过完全排除所有不利主公伪造高胜率。

#### 内奸

- 使用完整常备主公池；
- 不人为只挑有利主公；
- 保留不同主公下的分层结果。

必须报告：

1. 全主公池平均；
2. 各具体主公分层；
3. 忠臣相性主公结果；
4. 忠臣普通主公结果；
5. 反贼普通主公结果；
6. 反贼遭遇明显克制主公的专项结果；
7. 被测武将强制主公结果。

相性与克制名单必须在运行前登记，不得根据运行结果倒推名单。

## 五、通用结算与信息规则增量
==================================================

### 1. 距离1以内包括自己

【当前确认】

技能写“与你距离1以内的角色”，且没有：

- 排除“你”；
- 写“其他角色”；
- 或其他明确排除自身的文字；

则：

- 角色与自己的距离为0；
- 自己属于距离1以内；
- 距离为0满足距离不大于1。

鲍信【毅谋】因此可以由鲍信本人受到伤害触发。

### 2. 隐藏信息

【当前确认】

身份局：

- AI不能读取未公开身份；
- AI不能读取未公开手牌；
- 只能根据公开行为和已知牌移动建立概率判断。

2v2：

- 队友之间可以看见彼此完整手牌。

斗地主农民：

- 可以通过送花、砸蛋等约定方式表示有桃或无桃；
- 可以通过送花确认队友当前手牌中的【杀】数量；
- 只确认当前约定的信息；
- 不自动公开完整手牌；
- 不自动公开花色、点数或其他牌名；
- 敌方地主完整手牌仍不可见。

敌方隐藏手牌只能根据以下信息估计：

- 公开使用；
- 公开打出；
- 公开弃置；
- 公开获得；
- 已知转移；
- 合法观看；
- 响应读条等已有通用信息机制。

### 3. 当前卡名与仅在使用时视为

【当前确认】

统计“手牌中所有【杀】”时，包括：

- 实体原卡名为普通【杀】；
- 实体原卡名为火【杀】；
- 实体原卡名为雷【杀】；
- 某个持续效果已经实际把该实体牌当前卡名修改为【杀】的牌。

不包括：

- 只有在使用或打出时才能临时视为【杀】的材料牌；
- 武将牌旁特殊区的牌，除非技能明确把它们计作手牌；
- 只在某次结算中临时当【杀】使用，但当前手牌卡名并未改变的牌。

建议区分：

- `original_card_name`
- `current_card_name`
- `use_as_card_name`
- `physical_zone`
- `counts_as_hand_card`

### 4. 已生成牌效果与来源死亡

【当前确认】

牌或虚拟牌已经合法生成并开始结算后，来源角色死亡不自动取消未完成结算。

只有以下情况停止：

1. 游戏已经因胜利条件结束；
2. 规则明确要求来源必须存活；
3. 后续步骤本身因为来源死亡无法合法继续；
4. 目标、距离或其他必要条件在后续重新检查时不再成立。

魏文鸯【椎锋】示例：

- 文鸯流失最后1点体力并死亡；
- 已生成的虚拟【决斗】仍开始并继续结算；
- 目标打出一张【杀】后；
- 已死亡的文鸯无法继续打出【杀】；
- 因而该次【决斗】在此处结束。

不得在来源死亡时直接删除已经生成的牌使用事件。

### 5. 伤害来源与身份奖惩

【当前确认】

若技能明确令A对B造成伤害：

- 伤害来源是A；
- 技能发动者不自动成为伤害来源；
- A击杀反贼时，击杀奖励归A；
- A是主公并击杀忠臣时，误杀忠臣惩罚归主公A；
- 其他依赖伤害来源的技能读取A。

鲍信【募讨】的伤害来源：

- 是被选择并交出【杀】的原目标；
- 不是鲍信。

### 6. 终止延时锦囊判定

【当前确认】

黑桃判定被【讨乱】完全终止时：

1. 原判定结果不生效。
2. 若判定由判定区内的延时锦囊发起：
   - 延时锦囊本体留在原判定区；
   - 该延时锦囊本回合不再重复处理。
3. 翻开的判定牌与延时锦囊本体是两张不同的牌。
4. 选择获得判定牌时：
   - 谋皇甫嵩获得翻开的判定牌。
5. 不选择获得判定牌、改为使用火【杀】时：
   - 翻开的判定牌进入弃牌堆。
6. 不得把延时锦囊本体随判定牌一起置入弃牌堆。

## 六、徐荣
==================================================

### 1. 徐荣基础信息

- 版本：当前采用移动版截图／本轮确认版本；
- 势力：群；
- 体力：4；
- 技能：【凶镬】【杀绝】。

### 2. 【凶镬】

**内容类型：用户提供的规则原文摘要（资料状态：用户整理解释）**

游戏开始时，徐荣拥有3枚“暴戾”。

徐荣可以将暴戾分配给没有暴戾的其他角色。

徐荣对有暴戾的角色造成伤害时，此伤害增加1点。

有暴戾角色出牌阶段开始时，移去其暴戾并随机执行一项：

1. 受到1点火焰伤害，且本回合不能对徐荣使用【杀】；
2. 失去1点体力，且本回合手牌上限减少1；
3. 徐荣随机获得其一张手牌和装备区一张牌。

第三项处理：

- 手牌区没有牌时，不获得手牌；
- 装备区没有牌时，不获得装备；
- 两区均有牌时，各随机获得一张；
- 只获得实际存在的部分。

【分析约定】

暴戾分配优先级：

1. 当前可形成击杀或深度濒死的敌人；
2. 已横置，可与另一名暴戾敌人形成属性连环的角色；
3. 手牌少、已打出【闪】或过牌能力低的角色；
4. 即将行动且随机惩罚期望高的角色；
5. 身份未明时，避免把全部暴戾过早投给同一阵营推定目标。

### 3. 【杀绝】

**内容类型：用户提供的规则原文摘要（资料状态：用户整理解释）**

其他角色因伤害进入深度濒死，即体力值低于0时，徐荣获得一枚暴戾，并获得造成此次伤害的牌。

【当前确认】

- 每次满足条件的濒死事件分别检查；
- 只在目标体力低于0时触发；
- 体力恰好为0不触发；
- 伤害牌仍在处理区且可取得时，徐荣获得对应实体牌；
- 同一角色被救回后，再次被伤害打入低于0，可以再次触发；
- 徐荣自己进入低于0状态不满足“其他角色”；
- 伤害牌已经离开处理区、被其他效果取得或不存在实体牌时：
  - 只获得暴戾；
  - 不凭空生成卡牌。

### 4. 装备与牌序策略

【当前确认】与【分析约定】

徐荣长期提高以下牌的保留权重：

- 【贯石斧】；
- 【诸葛连弩】；
- 【青龙偃月刀】；
- 【铁索连环】；
- 火【杀】；
- 雷【杀】；
- 【火攻】；
- 【决斗】；
- 【南蛮入侵】；
- 【万箭齐发】；
- 【过河拆桥】；
- 【顺手牵羊】。

#### 贯石斧

- 即使当前没有【杀】，只要装备未被拆，后续摸到【杀】仍能产生长期收益；
- 只在击杀、深度濒死、双暴戾连环或高价值指定目标时，显著提高弃两牌强制命中的意愿；
- 不为普通1点低收益伤害无脑消耗两张关键牌。

#### 诸葛连弩

- 可以长期积累【杀】后形成爆发；
- 【杀绝】回收伤害牌后，可以再次使用；
- 对手已使用过【闪】、手牌少或防御资源低时优先收割；
- 内奸不能为了早期无关击杀耗尽连弩、暴戾和全部输出牌。

#### 青龙偃月刀

- 视为较弱的连续命中工具；
- 距离按武器实际攻击范围计算；
- 不得写成天然无视距离；
- 多次追【杀】前评估目标剩余【闪】、自身资源和击杀概率。

### 5. 双暴戾连环

【当前确认】

两名有暴戾的敌方角色均处于连环状态，徐荣以属性【杀】命中时：

- 原目标受到属性伤害；
- 原目标有暴戾，伤害增加1；
- 属性伤害传导到另一名横置角色；
- 另一名角色有暴戾，传导伤害也增加1；
- 每名受伤角色分别读取自己的暴戾状态；
- 不得只给原目标加伤；
- 每名角色分别更新：
  - 体力；
  - 濒死；
  - 【杀绝】；
  - 连环解除；
  - 其他伤害后技能。

相比普通单目标1点【杀】，该路线可能形成额外3点总伤害价值，应高于无目的单点消耗。

### 6. 内奸策略

【当前确认】与【分析约定】

徐荣内奸是收割角色，不是无条件主动击杀者。

- 长线保留暴戾、武器、属性【杀】和伤害锦囊；
- 等待其他阵营消耗目标【闪】后，提高目标优先级；
- 不因阵容标签，在明显不能造成有效伤害时无脑出牌；
- 显著低收益攻击可以放弃；
- 优先让其他阵营互相消耗；
- 再通过贯石斧、连弩、青龙和【杀绝】循环收割；
- 过早耗尽暴戾和输出牌后会接近白板，AI必须显式规避。

### 7. 当前定位

**内容类型：用户提供的既有模拟结果摘要（本轮未重新运行）**

在此前较弱将池中：

- 五人身份平均偏弱；
- 2v2为中等偏强；
- 斗地主为强农民、弱地主；
- 不作为全模式平滑的纯中等基准；
- 可作为2v2和斗地主农民的进攻专项样本。

4. 令其获得“节谏”标记。

  - 不改变原目标；
  - 仍进入原目标判定区；
  - 王经可以发动并摸1张牌。

- 移除时若其当前体力不低于记录值，王经摸2张；

3. 背水：执行前两项，然后减少1点体力上限。

【当前确认】

普通发动：

- 第一项和第二项二选一；
- 不能同时执行。

背水：

1. 先执行第一项；
2. 再执行第二项；
3. 最后减少1点体力上限。

若第一项获得的牌是基本牌：

- 可以把该牌作为第二项弃置材料。

所有“背水”统一按：

`先1 → 后2 → 最后支付背水代价`

结算。

次数：

- 每回合基础限1次；
- 【仇决】增加额外发动次数；

### 4. 魏文鸯【椎锋】

**内容类型：用户提供的规则原文摘要（资料状态：用户整理解释）**

出牌阶段限两次。

若该【决斗】对文鸯造成伤害：

- 防止该伤害；
- 【椎锋】失效直到本阶段结束。

【当前确认】

- 流失体力不是受到伤害；
- 无伤害来源；
- 不触发受到伤害后技能；
- 可以导致文鸯死亡；
- 即使文鸯因流失体力死亡，已经合法生成的虚拟【决斗】仍继续结算；

- 后续【决斗】立即结束。

AI策略：

- 不应为了帮助忠臣换掉反贼而主动摧毁自己的残局能力。

### 5. 吴文鸯【冲坚】

**内容类型：用户提供的规则原文摘要（资料状态：用户整理解释）**

【当前确认】与【分析约定】

只有以下情况提高装备意愿：

- 当回合能直接击杀吴文鸯；
- 连弩当回合净收益足够高；

- 吴文鸯无法合法命中；

- 连弩暂留手牌；
- 避免被吴文鸯通过【冲坚】夺取；
- 避免让吴文鸯启动全场装备循环。

### 7. 路线嘲讽

【分析约定】

## 十、鲍信
==================================================

### 1. 鲍信基础信息

- 势力：群；
- 体力：4；
- 八人主公：5；
- 技能：【募讨】【毅谋】；

### 2. 【募讨】

**内容类型：用户提供的规则原文摘要（资料状态：用户整理解释）**

出牌阶段限一次，选择一名角色。

其将手牌中所有【杀】置于武将牌上，然后从其下家开始，依次把这些【杀】随机交给每一名角色。

分发完毕后，原目标对最后一名实际获得【杀】的角色造成X点伤害。

X为该角色分发结束后手牌中【杀】的数量，且至多为2。

### 3. 【募讨】十一项裁定

【当前确认】

1. 原目标手中没有【杀】时仍可以发动，但不产生后续分发和伤害效果。
2. 发动前不能通过技能合法性检查知道目标是否有【杀】。
3. 分发从原目标下家开始。
4. 每名角色不是至多获得一张。
5. 【杀】数量足够时继续沿存活角色环绕圈分发。
6. 绕一圈后原目标本人也可能获得【杀】。
7. 持续分发直到所有【杀】发完。
8. “最后一名角色”严格指最后实际收到一张【杀】的角色。
9. 原目标本人也可能成为最后接收者，并对自己造成伤害。
10. X读取分发结束后最后接收者手牌中的全部【杀】，包括刚获得的牌。
11. X至多为2。

“手牌中所有【杀】”包括：

- 实体当前卡名为普通【杀】；
- 火【杀】；
- 雷【杀】；
- 持续效果已经真正改写当前卡名为【杀】的牌。

不包括：

- 仅在使用时视为【杀】的材料牌；
- 武将牌旁特殊区牌；
- 临时转化身份但手牌当前卡名未改变的牌。

### 4. 伤害来源与属性

【当前确认】

【募讨】最终伤害：

- 来源是原目标；
- 不是鲍信；
- 是无属性伤害；
- 不是【杀】造成；
- 不受攻击距离影响；
- 不允许通过【闪】响应；
- 正常触发造成伤害、受到伤害和伤害来源相关技能；
- 击杀奖励与身份惩罚归原目标。

### 5. 【毅谋】

**内容类型：用户提供的规则原文摘要（资料状态：用户整理解释）**

与鲍信距离1以内的角色受到伤害后，鲍信可以选择：

1. 令受伤角色随机获得牌堆中的一张【杀】；
2. 令受伤角色将一张手牌交给另一名角色，然后该受伤角色摸1张牌。

【当前确认】

- 距离1以内包括鲍信本人；
- 第二项交出的手牌由受伤角色选择；
- 接收牌的另一名角色也由受伤角色选择；
- 受伤角色没有手牌时，第二项不可选；
- 交出的手牌不公开给无权查看的角色；
- 没有每回合次数限制；
- 每个独立伤害事件触发一次；
- 一次2点或更多伤害仍只触发一次；
- 多次独立伤害分别触发。

### 6. 信息与模式

#### 2v2

队友手牌完整可见，因此可以精确知道：

- 队友当前【杀】数量；
- 可能的最后接收者；
- 【募讨】可能造成1点还是2点伤害。

#### 斗地主农民

【当前确认】

据此判断：

- 是否能把最后一张【杀】分发给地主；

不得因此公开：
